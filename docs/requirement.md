# 요구사항 정의서

---

### 1. 목적

취업 정보 공유 게시판 + 스터디 모집 기능을 갖춘 **취준생 커뮤니티 SNS**를 구현하고, 팀 협업 루틴(Git·PR·데모)을 심화한다.

### 2. 필수 기능 (MVP)

#### 회원/인증

| ID | 기능 | 설명 | 완료 기준 |
| --- | --- | --- | --- |
| F-01 | 회원가입 | 아이디·비밀번호·역할 | 비밀번호 암호화 저장, 201 |
| F-02 | 로그인(JWT, OAuth2) | 토큰 발급, 카카오톡 로그인 | `Authorization: Bearer` 사용 |

#### 게시판

| ID | 기능 | 설명 | 완료 기준 |
| --- | --- | --- | --- |
| F-03 | 게시글 등록 | 로그인 사용자가 질문 등록 | 작성자 자동 기록, 201 |
| F-04 | 게시글 목록/상세 | 페이징·최신순·카테고리 정렬 | page, size 파라미터 동작 |
| F-05 | 게시글 수정/삭제 | 작성자 본인 또는 ADMIN | 타인 수정/삭제 403 |
| F-06 | 댓글 등록 | 게시글에 답변 1:N | 로그인 사용자, Answer 저장 |

#### 스터디

| ID | 기능 | 설명 | 완료 기준 |
| --- | --- | --- | --- |
| F-07 | 스터디 개설 | 제목·모집인원·모집기간·설명 | 작성자 자동 기록, 201 |
| F-08 | 스터디 목록/상세 | 글 목록, 페이징, 검색, 카테고리 정렬 | page, size 파라미터 동작, 키워드 검색 |
| F-09 | 스터디 수정/삭제 | 방장 본인 또는 ADMIN | 타인 수정/삭제 403 |
| F-10 | 스터디 신청 | USER가 참여 신청 | 방장 신청 불가, 중복 신청 불가, 정원초과 시 불가, 
참여그룹 2개 초과 시 불가 |
| F-11 | 그룹 내 유저 관리 | 방장만 가능 | 방장 아닌 사용자 처리 시 403 |
| F-12 | 채팅방 | 승인된 유저만 가능 | 승인된 유저가 아닐 시 403 |

#### 관리자

| ID | 기능 | 설명 | 완료 기준 |
| --- | --- | --- | --- |
| F-13 | 전체 게시판 관리, 스터디 그룹 관리 | ADMIN이 모든 게시글 삭제 가능 | ADMIN 아닌 경우 403 |
| F-14 | 유저 관리 | ADMIN이 USER 목록 조회 및 
계정 상태 변경 | USER 상태 변경 |

#### 공통

| ID | 기능 | 설명 | 완료 기준 |
| --- | --- | --- | --- |
| F-15 | 입력 검증 | 빈 제목·과도한 길이 등 | 400 + 메시지 |

#### 화면(FE)

| ID | 기능 | 설명 | 완료 기준 |
| --- | --- | --- | --- |
| F-UI-01 | 로그인·회원가입 화면 | JWT 저장 | 로그인 후 토큰으로 API 호출 |
| F-UI-02 | 게시글 목록 | 페이징 UI, 카테고리 정렬, 검색  | page/size 동작, 비로그인 조회 |
| F-UI-03 | 게시글 상세·댓글 | 상세+댓글 목록 | API 응답 그대로 표시 |
| F-UI-04 | 게시글 작성·수정 | 폼 + 권한별 버튼 | 본인만 수정·삭제 버튼 |
| F-UI-05 | 스터디 목록 | 페이징 UI, 카테고리 정렬, 검색  | page/size 동작, 비로그인 조회 |
| F-UI-06 | 스터디 상세·채팅 | 상세+채팅(스크롤) | API 응답 그대로 표시 |
| F-UI-07 | 스터디 개설·수정 | 폼 + 권한별 버튼 | 방장만 수정·삭제 버튼 |
| F-UI-08 | 권한 UX | 401/403 처리 | 비로그인 쓰기 시 로그인 유도 |
| F-UI-09 | 관리자 화면 | 게시글, 스터디 그룹, 유저 관리 | ADMIN만 접근 가능 |

### 3. 하지 않을 것

- 실시간 채팅
- 파일 첨부
- 좋아요 · 스크랩
