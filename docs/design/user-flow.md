- UF-10. 마이페이지 설정 → 닉네임·비밀번호·결제수단·회원 탈퇴

    회원 탈퇴는 방장이어도 가능하며, 방장인 스터디는 소프트 삭제됩니다(기존 “방장이면 탈퇴 불가”는 코드와 달라 바로잡음). 탈퇴 계정의 작성글은 “탈퇴한 사용자”로 표기됩니다(F-43).

- UF-12. 정기결제 실패 → 유예 → 재시도 → 복구 또는 종료
    
    > 결제가 실패해도 이미 결제된 기간까지는 그대로 이용합니다. 그 기간이 끝나면 유료 기능이 막히고(상태는 PAST_DUE 유지), 하루 1회 자동 재시도가 이어집니다. 자동 재시도 3회를 모두 실패하면 구독이 종료됩니다. 사용자는 언제든 즉시 재결제할 수 있고, 성공하면 바로 복구됩니다.
    > 
    
    ![UF-12](images/user-flow/UF-12.png)
    
    UF-12
    
- UF-13. 구독 해지(자동 갱신 예약 취소) → 재개
    
    > 해지는 즉시 종료가 아니라 “다음 회차 자동 결제만 중단”입니다(autoRenew=false). 만료일까지는 계속 이용하고, 만료 전이면 다시 켤 수 있습니다.

- UF-14. 결제수단 등록·변경·삭제 (마이페이지 설정)
    
    > 카드번호·유효기간·CVC는 서버에 저장하지 않고 PortOne이 발급한 빌링키만 보관합니다(암호화). 유저당 카드 1장이라 새로 등록하면 기존 카드는 교체됩니다. 삭제하면 PortOne과 서버 양쪽에서 빌링키를 폐기하고, 구독 중이면 자동 갱신도 함께 해지됩니다. 90일간 청구에 쓰이지 않은 카드는 자동 정리됩니다(F-65).
    > 
    
    UF-14
    
    ![UF-14](images/user-flow/UF-14.png)
    
    UF-14
    
- UF-15. 결제 웹훅 수신 → 상태 동기화 (시스템 흐름)
    
    > PortOne이 결제 상태 변화를 웹훅으로 알려줍니다. 서명(webhook-id·signature·timestamp)을 검증하고 webhook-id로 중복을 거른 뒤, 결제 단건을 재조회해(완료 API와 동일한 검증) 상태를 반영합니다. PG 콘솔 취소·카드사 사후 취소·청구 타임아웃 결과 미확인 건을 잡아냅니다. 청구 트리거는 스케줄러 그대로이며(예약 API 미사용), 웹훅은 상태 동기화 용도입니다.
    > 
    
    UF-15
